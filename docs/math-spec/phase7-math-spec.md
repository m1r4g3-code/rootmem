# Phase 7 Math Spec

**N/A, with justification.** Phase 7 adds no new scoring, ranking, decay or belief-update logic — it invokes the existing `search`/`rank_score` and `remember` paths automatically, unchanged (ADR 0042). The only new numeric parameters are thresholds, not formulas: `ROOTMEM_AUTO_RECALL_LIMIT` (how many top-ranked results to inject, default 3), `ROOTMEM_AUTO_RECALL_MIN_SCORE` (a floor below which nothing is injected, default 0.0 — the existing ranker's own ordering is trusted unless an operator says otherwise), `ROOTMEM_AUTO_CAPTURE_MIN_CHARS` (a length floor below which a turn is not captured, default 40, chosen to skip one- or two-word acknowledgements without needing content analysis). None of these are derived; all are provisional defaults in the same spirit as every other threshold this project has shipped, revisited only if real dogfooding shows they're wrong.
